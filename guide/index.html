1STRIDE でできること

  • 体重・体脂肪率、筋トレ（重量・回数）、ジョギング（距離・時間）、食事のカロリー・歩数を記録する
  • グラフやカレンダーで変化を見る。自己ベストを更新するとお祝いの紙吹雪が出る
  • 目標体重を決めると、目標までの残りや 1 日のカロリーの目安を表示する
  • やること（タスク）を管理する
記録はあなた専用の保存場所に暗号化して保存されます。家族の誰か（管理者を含む）が中身を見ることはできません。

2用意するもの・言葉の説明

家族（管理者）から受け取るメモ

リポジトリ名例：tk1192-creator/stride-○○
トークンgithub_pat_ で始まる長い文字列
トークンはパスワードと同じ大切なものです。AirDrop や手渡しのメモで受け取り、LINE やメールでは送らないようにしてください。

自分で決めるもの

合言葉8 文字以上。自分だけが知っている言葉
合言葉を忘れると、記録を二度と開けなくなります。紙に書いて、なくさない場所に保管してください。

言葉の説明

リポジトリ
記録を保存しておく「箱」のこと。インターネット上（GitHub というサービス）にあり、あなた専用で他の人には見えません（非公開）。
トークン
その箱に記録を書き込むための「鍵」。あなたの箱にだけ使えます。
合言葉
記録を暗号化する（他の人が読めないようにする）ための言葉。箱の中身は、この合言葉がないと読めません。
ホーム画面に追加
ウェブのページを、アプリのようにアイコンから開けるようにすること。電波がなくても使えます。

3iPhone のホーム画面に追加する

  1. Safari（青いコンパスのアイコン）で、次のアドレスを開きます。
    https://tk1192-creator.github.io/fitlog/
    Safari で STRIDE を開いたところ（画面上部に「Safari で開いています」の案内が出ている）
  2. 画面の下にある共有ボタン（四角から上向きの矢印が出ているアイコン）をタップします。
    共有ボタンの位置を赤丸で示した画面
  3. 出てきたメニューを上にスクロールし、「ホーム画面に追加」をタップします。
    メニューの中の「ホーム画面に追加」
  4. 名前が「STRIDE」になっていることを確認して、右上の「追加」をタップします。
  5. ホーム画面に STRIDE のアイコン（青い四角に白い矢印）ができます。これ以降は、必ずこのアイコンから開いてください。
    ホーム画面に追加された STRIDE のアイコン
Safari で開いたまま記録をつけると、ホーム画面のアイコンから開いたときに表示されません（保存場所が別のため）。

4記録の保存先を設定する（最初に必ず）

この設定をしないと、記録は iPhone の中にしか残らず、アイコンを消したときに一緒に消えてしまいます。

  1. ホーム画面の STRIDE アイコンから開きます。
  2. 画面いちばん下の右端にある ⚙ 設定 をタップします。
  3. いちばん上の「記録の保存先（GitHub）」の欄に、次のとおり入力します。
    欄入れるもの
    リポジトリ受け取ったメモの「リポジトリ名」（例：tk1192-creator/stride-○○）
    トークン受け取ったメモの github_pat_…（長押し →「ペースト」で貼り付けると確実です）
    合言葉自分で決めた合言葉
    合言葉（確認）同じ合言葉をもう一度
    「記録の保存先（GitHub）」の入力欄に入力したところ
  4. 「タスクも暗号化して保存する」は、チェックを入れなくてかまいません（タスクを使う人だけ）。
  5. 接続して保存を始める をタップします。
  6. 「GitHub への保存を始めました」と出て、画面左上の「STRIDE›」の横にある雲のアイコンが青になれば完了です。
    設定完了後の画面（「GitHub に保存：保存済み」と雲のアイコンが青）

雲のアイコンの見方

色意味
青保存済み（安心してください）
点滅保存中・保存待ち
灰色電波がない。つながったら自動で保存します
赤未設定、またはエラー。タップすると設定画面が開きます

5プロフィールを入力する

  1. ⚙ 設定 の「プロフィール・目標」に、身長・年齢を入力します。
  2. 目標体重（と、あれば目標の日付）、週に何日運動したいか、1 日の歩数の目標を入れます。
  3. カロリーの目安を出したい場合は、性別と活動レベル（ふだんどのくらい体を動かすか）も選びます。
  4. 設定を保存 をタップします。
    「プロフィール・目標」の入力欄

6記録をつける

  1. ⌂ ホーム の「体重」「筋トレ」「ジョギング」のボタン、または下の ＋ 記録 をタップします。
  2. 上の切り替え（体重／筋トレ／ジョギング／食事・歩数）で、記録する種類を選びます。
  3. 数字を入れて 保存する をタップします。日付は最初から「今日」になっています。
    体重の記録画面（日付・体重・体脂肪率の欄と「保存する」ボタン）
  4. まちがえたときは、記録画面の下の一覧から該当の記録をタップすると、直したり消したりできます。
記録すると、数秒後に自動で保存先に保存されます（雲のアイコンが青に戻れば保存済み）。

7便利な機能

画面できること
ホーム →「目標」今のペース（直近 4 週の体重の傾向。1 週間あたり何 kg 変わっているか）と、達成見込み（そのペースが続いたら目標体重に届く日）。体重を 2 週間以上・5 回以上記録すると表示されます
ホーム →「今日のカロリー・歩数」記録から見た実際の消費：食事の記録（平均）と体重の変化から、1 日に実際に使っているカロリーを推定します。食事を直近 4 週で 14 日以上記録すると表示されます。食事の記録漏れがあると低めに出ます
グラフ体重の変化（点線は今のペースが続いた場合の予測）、筋トレの重量の伸び、ジョギングの距離、食事・歩数。上のボタンで期間（1 か月〜全期間）を切り替え
カレンダー運動した日に印が付きます。タスクの期限がある日には四角い印（期限切れは赤）。日付をタップするとその日の記録と、その日が期限のタスク
ホーム →「先週のふりかえり」月〜水曜に、先週の運動日数（前の週との比較）・体重の週平均・自己ベスト・獲得したバッジを表示。「×」で閉じるとその週は出ません
ホーム →「目標」の 🎯目標までを 1kg ごとの節目に分け、次の節目までの残りを表示。7 日平均で節目を越えると紙吹雪でお祝いします（1 日だけ軽かった日では出ません）
グラフ →「自己ベスト」のバッジ「運動 50 日」「累計 100km」「開始時から −5kg」など 28 個。これまでの記録で達成済みのものは最初から獲得済み。未獲得は残りを表示。ホームの「今週の運動」の「🏅 バッジ」からも開けます
タスクやることの管理。右下の「＋」で追加
設定 → Face ID でロックアプリを開くときに顔認証を求めます（人に iPhone を貸すときに安心）

8入力忘れのお知らせ（通知）

毎日 21 時ごろ、その日の体重がまだ記録されていないときだけ、iPhone に通知が届きます。記録済みの日は届きません。

先に手順 4（記録の保存先）を済ませておく必要があります。また、管理者が通知の準備（手順 12）を済ませている必要があります。iOS 16.4 以降で使えます。
  1. ホーム画面の STRIDE アイコンから開きます（Safari からでは通知を受け取れません）。
  2. ⚙ 設定 →「記録の保存先（GitHub）」の欄の下にある「入力忘れのお知らせ」で、この端末で通知を受け取る をタップします。
  3. 「“STRIDE”は通知を送信します。よろしいですか？」と出たら 「許可」をタップします。
    通知の許可を求める画面（「許可」をタップ）
  4. 「🔔 この端末で受け取る：オン」になれば完了です。
  • 通知をタップすると STRIDE の記録画面が開きます。
  • 届く時刻は、混み具合で数分〜数十分遅れることがあります。
  • 止めたいときは、同じ場所の この端末の通知を止める をタップします。

通知が使えない端末の場合（「ショートカット」アプリで毎日知らせる）

記録したかどうかに関係なく、毎日決まった時刻に知らせる方法です。プログラムの準備は不要です。

  1. iPhone の「ショートカット」アプリを開き、下の「オートメーション」→ 右上の「＋」をタップします。
  2. 「時刻」を選び、時刻を「21:00」、繰り返しを「毎日」にし、「すぐに実行」を選んで「次へ」。
  3. 「新規の空のショートカット」→ アクションの検索で「通知を表示」を追加し、文章を「今日の体重を記録しましょう」にして「完了」。

画面の名前は iOS のバージョンによって少し違うことがあります（要確認）。

9歩数の自動取り込み（ヘルスケア）

iPhone の「ヘルスケア」の歩数を、毎日自動で STRIDE に取り込みます。「ショートカット」アプリが歩数を読み取り、あなたの保存先（受け取り箱）に送り、STRIDE が次に開いたときに取り込みます。

先に手順 4（記録の保存先）を済ませておく必要があります。歩数用のトークン（手順 12 で管理者からもらう「歩数用」）を使います。
受け取り箱に置いた歩数と日付は、STRIDE が取り込むまで暗号化されません（取り込んだら消えます）。

ショートカットを作る（最初に 1 回）

  1. 「ショートカット」アプリ → 右上の「＋」で新しいショートカットを作り、名前を「STRIDE 歩数」にします。
  2. アクション「ヘルスケアサンプルを検索」を追加し、種類を「歩数」、条件を「開始日」が「今日」にします（初回はヘルスケアへのアクセスの許可を求められるので「許可」）。
  3. アクション「統計を計算」を追加し、「合計」にします（入力は「ヘルスケアサンプル」）。
  4. アクション「日付を書式設定」を追加し、日付を「現在の日付」、書式を「カスタム」で yyyy-MM-dd にします。
  5. もう一つ「日付を書式設定」を追加し、書式を「カスタム」で yyyy-MM-dd-HHmmss にします。
  6. アクション「テキスト」を追加し、次のように入力します（［ ］の部分は、前の手順の結果を「変数」として差し込みます）。
    {"date":"［手順 4 の日付］","steps":［統計］}
  7. アクション「Base64 エンコード」を追加します（入力は「テキスト」。改行の設定があれば「なし」）。
  8. アクション「URL の内容を取得」を追加し、次のとおり設定します。
    項目設定
    URLhttps://api.github.com/repos/［あなたのリポジトリ名］/contents/inbox/steps-［手順 5 の日付］.json
    方法PUT
    ヘッダAuthorization：Bearer ［歩数用のトークン］
    Accept：application/vnd.github+json
    本文を要求JSON。message（テキスト）：steps、content（テキスト）：［Base64 エンコードの結果］
    「URL の内容を取得」の設定画面（方法・ヘッダ・本文）
  9. 右上の ▶（実行）で試します。エラーが出なければ、次に STRIDE を開いたときに「記録 → 食事・歩数」に今日の歩数が入ります。

毎日自動で動かす

  1. 「ショートカット」アプリ → 「オートメーション」→「＋」→「時刻」。
  2. 時刻を「22:30」など、iPhone を使っていることが多い時間にし、「毎日」「すぐに実行」を選びます。
  3. 「STRIDE 歩数」を選んで完了です。
iPhone がロックされていると、ヘルスケアのデータを読めずに失敗することがあります（要確認）。うまく動かない日は、寝る前に「STRIDE 歩数」を手動で実行してください。また、日付が変わる前（24 時より前）に実行してください。

10LINE で受け取る（入力忘れ・家族への報告）

LINE 公式アカウント「STRIDE」を友だち追加すると、次のメッセージが LINE に届きます。

メッセージ届く相手いつ
入力忘れのお知らせ本人だけ（管理者が設定した人）21 時ごろ、その日の体重がまだのとき
今週のふりかえり家族全員（友だち追加した人）日曜の夜 21 時ごろ
自己ベストの報告家族全員記録してから 1 分ほどで

家族のみなさんがすること

  1. 管理者から LINE 公式アカウント「STRIDE」の友だち追加用の QR コードを見せてもらい、LINE の「友だち追加」→「QR コード」で読み取って追加します。
    LINE で「STRIDE」を友だち追加したところ
  2. 自分の記録を家族に報告したい人は、STRIDE の ⚙ 設定 →「LINE で家族に報告」で、
    • 「家族に報告する」にチェック
    • 「家族に表示する名前」を入力（例：ママ）
    • 送る内容（今週のふりかえり・自己ベスト・体重の増減）を選ぶ
    を設定して 報告の設定を保存 をタップします。
体重そのものは送りません。「体重の増減も含める」をオンにしたときだけ「今週 −0.6kg」のように増減を送ります。送った内容は LINE のサーバーを通ります。

11してはいけないこと・困ったとき

保存先の設定（手順 4）が終わる前に、ホーム画面の STRIDE アイコンを削除しないでください。記録が消えます。
困ったことどうするか
アイコンを消してしまった・iPhone を買い替えた手順 3 でもう一度ホーム画面に追加し、手順 4 で同じリポジトリ名・トークン・合言葉を入れます。「GitHub に記録があります」と出たら「GitHub の記録を使う」を選ぶと、記録が戻ります
「更新があります」と出た「再読み込み」をタップします（記録は消えません）
雲のアイコンが赤で「トークンが無効か期限切れ」トークンの期限切れです。家族（管理者）に新しいトークンをもらい、設定で「この端末の接続を解除」→ 手順 4 をやり直します
「合言葉が違います」と出る最初に決めた合言葉と違います。控えたメモを確認してください
記録が表示されないSafari で開いていないか確認し、ホーム画面のアイコンから開き直します

12管理者向け：家族の保存先とトークンを用意する

家族の保存先（非公開リポジトリ）は、管理者の GitHub アカウントに作ります。家族は GitHub のアカウントがなくても使えます。

トークンを作る（家族 1 人につき 1 つ）

  1. パソコンで GitHub のトークン作成画面を開きます（GitHub にサインインした状態で）。
  2. Token name：わかる名前（例：STRIDE-家族の呼び名）。Expiration：1 年以内。
  3. Repository access：「Only select repositories」→ その家族のリポジトリ（例：stride-○○）だけを選びます。
  4. Permissions：Repository permissions の「Contents」を「Read and write」にします（「Metadata：Read-only」は自動で付きます）。ほかは変えません。
  5. Generate token を押し、表示された github_pat_… をコピーします（この画面を閉じると二度と表示されません）。

家族に渡す

  • リポジトリ名とトークンを、AirDrop か手書きのメモで渡します。LINE・メールでは送らないでください。
  • 合言葉は家族自身に決めてもらい、管理者は聞かないでください（中身が読めない状態を保つため）。
  • トークンの期限が近づいたら、同じ手順で作り直して渡します。古いトークンは GitHub の画面から削除します。

歩数用のトークン（手順 9 を使う人だけ）

上と同じ手順で、名前を STRIDE-歩数-家族の呼び名 にして、もう 1 つ作ります（対象リポジトリと権限は同じ）。STRIDE 用とは別にしておくと、iPhone をなくしたときに歩数用だけを止められます。

入力忘れのお知らせの準備（最初に 1 回）

  1. パソコンで、STRIDE のプログラムのフォルダ（fitlog）を開いた PowerShell で、次を実行します（保存先を並べて指定）。
    python tools/notify/setup_notify.py tk1192-creator/stride-○○ tk1192-creator/stride-△△
  2. 「準備しました」と出れば完了です。各保存先に、通知を送る仕組み（毎日 21 時ごろに動く）と、通知用の鍵が設定されます（秘密鍵は GitHub の「シークレット」に保存され、画面には出ません）。
  3. 家族を追加したときなどにもう一度実行しても、すでに準備済みの保存先の鍵は作り直しません（送信の仕組みだけ更新）。鍵を作り直すと、各端末で通知の登録（止める → 受け取る）のやり直しが必要です。
  4. 家族に、手順 8 で「この端末で通知を受け取る」を押してもらいます。
  5. テスト通知を送るとき：gh workflow run remind.yml -R tk1192-creator/stride-○○ -f test=true

LINE で受け取る準備（最初に 1 回）

  1. LINE 公式アカウントの作成ページで、自分の LINE アカウントでログインし、公式アカウントを作ります（アカウント名：STRIDE、無料のコミュニケーションプラン）。
  2. LINE Official Account Manager の「設定」→「Messaging API」→「Messaging API を利用する」を押し、プロバイダー（例：STRIDE）を作ります。
  3. 同じく「設定」→「応答設定」で、「あいさつメッセージ」「応答メッセージ」をオフにします（家族が話しかけても自動の返事が出ないように）。
  4. LINE Developers を開き、作ったプロバイダー → チャネルを選びます。
    • 「Messaging API 設定」タブの一番下「チャネルアクセストークン（長期）」で「発行」を押してコピーします（パスワードと同じ扱い）。
    • 「チャネル基本設定」タブの一番下「あなたのユーザー ID」（U で始まる 33 文字）を控えます。
    • 「Messaging API 設定」タブの QR コードで、自分と家族が友だち追加します。
  5. パソコンで、STRIDE のフォルダ（fitlog）を開いた PowerShell で次を実行します。
    python tools/notify/setup_line.py tk1192-creator/stride-○○ tk1192-creator/stride-△△
    聞かれたら、チャネルアクセストークン（画面には表示されません）と、各保存先の持ち主の LINE ユーザー ID（入力忘れを LINE でも受け取る人だけ。分からなければ空欄）を入れます。
  6. テスト：gh workflow run remind.yml -R tk1192-creator/stride-○○ -f test=true（入力忘れ）、gh workflow run weekly.yml -R tk1192-creator/stride-○○ -f test=true（ふりかえり。家族全員に届きます）
