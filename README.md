# STRIDE 運動・体重・タスク管理

（旧名: fitlog。URL・保存データは fitlog のまま引き継いでいます）

筋トレ・ジョギング・体重を毎日手軽に記録し、グラフ・カレンダー・自己ベストのお祝い表示で
変化を実感しながら運動を続けるための Web アプリ（PWA）です。

- 公開 URL: https://tk1192-creator.github.io/fitlog/
- スマホのホーム画面に追加すると、アプリのように全画面で起動し、オフラインでも記録できます。
- 記録はその端末のブラウザ内（localStorage）にだけ保存され、サーバーには送信されません。

## 主な機能

| 画面 | できること |
|---|---|
| ホーム | 現在の体重・BMI・開始時からの増減、目標までの残りと 1 週間あたりの目安、基礎代謝と 1 日のカロリーの目安・今日の摂取カロリーと歩数、今週の運動日数とストリーク、記録の入力ボタン |
| 記録 | 体重（体脂肪率・メモ）、筋トレ（種目・重量・回数・セット）、ジョギング（距離・時間）、食事・歩数（摂取 kcal・歩数）の入力・一覧・編集・削除。BMI・推定 1RM・ペースは自動計算 |
| グラフ | 体重（7 日移動平均・目標ライン）、体脂肪率、筋トレ（種目別の最大重量・推定 1RM）、ジョギング（月別合計距離・平均ペース）、食事・歩数（日別の摂取 kcal・歩数）、自己ベスト一覧。期間は 1か月／3か月／1年／全期間 |
| カレンダー | 運動した日の印（筋トレ＝オレンジ、ジョギング＝青）、週ごとの運動日数と目標達成週の強調、ストリーク、日付ごとの記録 |
| 設定 | 身長・年齢・目標体重・目標達成日・週の運動目標・歩数目標・性別・活動レベル、種目の追加削除、JSON エクスポート／インポート、CSV 出力、サンプルデータ生成・全削除 |

自己ベスト（筋トレの最大重量・推定 1RM、ジョギングの最長距離・最速ペース（3km 以上）、最低体重、目標体重の達成）を
更新すると、紙吹雪とメッセージでお祝いします。

基礎代謝は国立健康・栄養研究所の式による推定値、カロリーの目安は脂肪 1kg ≒ 7,200kcal で計算した目安です（医学的な判断ではありません）。

## タスク管理（Task Board）

下部タブの「タスク」で、タスク・案件の進捗管理ツール **Task Board** が開きます（`tasks/` フォルダ）。
一覧・ボード・ガントチャート・カレンダー表示、チェックリスト、繰り返し、報告文の作成などが使えます。
使い方は Task Board 画面右上の「?」（`tasks/manual.html`）を参照してください。
STRIDE のホームには、期限切れ・今日が期限・作業中の件数と、今日対応するタスクを表示します。

### データの扱い（重要）

| 版 | 保存場所 | 同期 | お客様情報 |
|---|---|---|---|
| STRIDE のタスク（この版） | その端末のブラウザ内（localStorage `taskBoard.data`） | なし | 会社の規定に従う（私用端末への保存可否は要確認） |
| PC のローカル版（元の Task Board） | PC のブラウザ内 | なし | お客様情報を含むタスクはこちらで扱う |
| claude.ai 版 | claude.ai のデータベース | PC と iPhone で自動同期 | **入力しない** |

- STRIDE のタスクはサーバーに送信しません。PC のローカル版・claude.ai 版とはデータを共有しません。
- 端末間でデータを移すときは「JSONをエクスポート」→「JSONからインポート」を使います。お客様情報を含む場合は、メールやクラウド（OneDrive など）を経由せず、AirDrop やケーブル接続で受け渡してください。
- GitHub Pages の保存領域は `tk1192-creator.github.io` 全体で共通です。このアカウントで STRIDE 以外のサイトを Pages に公開すると、そのサイトから Task Board のデータを読めてしまうため、公開しないでください。

### Task Board の修正と claude.ai 版

- 今後の Task Board の修正は、このリポジトリの `tasks/` を正とします（元のフォルダ `AI_自己管理ツール` は 2026-11-04 時点のまま残しています）。
- `tasks/app.js`・`tasks/style.css` は元の Task Board と同じ内容です。STRIDE との連携（見た目の統一・ダークモード・共通の下部タブ・保存場所の表示・オフライン対応）は `tasks/stride-bridge.js`・`tasks/stride-bridge.css` に分けており、claude.ai で開いたときは動きません。
- claude.ai 版を作り直すときは、Claude Code に「Task Board の claude.ai 版を、STRIDE の tasks/ で更新して」と依頼してください（claude.ai 版のリンクは公開リポジトリには載せず、Claude Code のメモリに記録しています）。

## 使い方

1. 設定画面で身長・年齢・目標体重（任意で目標達成日）・週の運動目標日数・歩数目標・性別・活動レベルを入力し、「設定を保存」を押す。
2. ホームの「＋体重」「＋筋トレ」「＋ジョギング」から記録する（日付の初期値は今日）。
3. 記録の修正・削除は、記録画面の一覧で対象をタップする。
4. 定期的に設定画面の「JSON でエクスポート」でバックアップを取る（14 日以上取っていないと注意が出ます）。

> **データについての注意**
> - 記録は端末・ブラウザごとに別々です。スマホと PC でデータは共有されません。PC で見たいときは、スマホでエクスポートした JSON を PC でインポートしてください。
> - iPhone では、Safari で開いたページとホーム画面に追加したアプリで保存場所が分かれる場合があります。記録はホーム画面のアプリに一本化してください。
> - ブラウザの「履歴・サイトデータの削除」をすると記録も消えます。
> - エクスポートしたファイル（*.json / *.csv）はリポジトリにコミットされないよう `.gitignore` で除外しています。

## ホーム画面への追加

### iPhone（Safari）

1. Safari で公開 URL を開く（Chrome など他のブラウザではなく Safari を使う）。
2. 画面下の共有ボタン（□に↑のアイコン）をタップする。
3. メニューを下にスクロールし、「ホーム画面に追加」をタップする。
4. 名前が「STRIDE」になっていることを確認し、右上の「追加」をタップする。
5. ホーム画面の STRIDE アイコンから起動する。

※ iOS のバージョンによってメニューの表記や位置が少し異なります（要確認）。

### Android（Chrome）

1. Chrome で公開 URL を開く。
2. 右上の「︙」メニューをタップする。
3. 「アプリをインストール」または「ホーム画面に追加」をタップする。
4. 確認画面で「インストール」（または「追加」）をタップする。
5. ホーム画面（またはアプリ一覧）の STRIDE アイコンから起動する。

## PC での動作確認（ローカルサーバー）

ES Modules と Service Worker を使っているため、`index.html` をダブルクリックで開くのではなく、ローカルサーバー経由で開きます。

```powershell
cd C:\Users\tk119\dev\fitlog
python -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。止めるときはターミナルで `Ctrl + C` を押します。

- 単体テスト: http://localhost:8000/tests/index.html を開くと、計算処理と自己ベスト判定のテストが実行されます（全件成功なら「すべて成功」と表示）。
- タスク画面は http://localhost:8000/tasks/ です。
- 開発中は Service Worker が古いファイルを返すことがあります（タスク画面を開いたときも登録されます）。`Ctrl + Shift + R` で再読み込みするか、
  Chrome の開発者ツール（F12）→「Application」→「Service workers」で「Update on reload」にチェックを入れてください。

## 修正を反映する流れ

1. ファイルを修正し、ローカルサーバーで動作を確認する。
2. `js/version.js` の `APP_VERSION` を上げる（例: `1.0.0` → `1.0.1`）。
   - これを上げないと、スマホ側に新しい版が届きません。
   - 新しいファイルを追加したときは、`sw.js` の `ASSETS` にも追記する。
3. コミットして push する。
   ```powershell
   git add -A
   git commit -m "修正内容がわかる日本語のメッセージ"
   git push
   ```
4. GitHub Actions が自動でデプロイします（1 分程度）。結果はリポジトリの「Actions」タブで確認できます。
5. スマホで STRIDE を開くと、上部に「更新があります」が表示されるので「再読み込み」をタップする。
   - すぐに表示されないときは、アプリを一度閉じて（バックグラウンドから消して）開き直す。
   - 記録データは更新しても消えません。

## ファイル構成

```
index.html            画面の枠（上部バー・下部タブ）
manifest.json         PWA の設定（アプリ名・アイコン・start_url / scope は ./）
sw.js                 Service Worker（キャッシュ名 fitlog-v<バージョン>）
css/style.css         スタイル（ライト / ダーク）
js/version.js         アプリのバージョン
js/app.js             初期化・タブ切替・日時表示
js/calc.js            計算処理（BMI・ペース・1RM・移動平均・週集計・ストリーク）
js/pb.js              自己ベスト判定
js/storage.js         保存・JSON / CSV 入出力
js/views/*.js         各画面（home-tasks.js はホームの「今日のタスク」）
tasks/                Task Board（タスク管理）。stride-bridge.* が STRIDE との連携部分
lib/                  Chart.js v4.5.0、canvas-confetti v1.9.3（オフライン動作のため同梱）
icons/                アプリアイコン（tools/make_icons.py で生成）
tests/                単体テスト（ブラウザで実行）
docs/design.md        設計書
```
